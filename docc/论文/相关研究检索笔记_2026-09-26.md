## 结论摘要

1. **没有一篇工作同时覆盖「透明杯 + 载水 + 端到端视觉策略 + 检测注入」四要素**。三条轴上各有近邻（载液防洒、透明物体、检测注入），本项目场景是空白区。
2. **模型侧最近邻是 RoboMP-DINOv2（arXiv:2609.25506）**：mask 作 prompt 做 token 级注入——与本项目 I0/I1 的注入哲学一致，写论文必引。
3. **决策：不换底座**（理由见"决策与建议"）；DP 同数据集对照已由 P4 的 `DIFFUSION_NM` 覆盖，与本次检索建议不谋而合。

### RoboMP-DINOv2 详解（模型侧最近邻）

- **定位**：面向机器人操纵的全场景视觉编码器。核心口号 **"Prompts, Not Filters"**——分割 mask 是空间 prompt（注入），不是可见性过滤（抠图）。object-centric 流派的抠图/mask-out 会丢掉对行为有用的场景上下文。
- **结构四段**：① DINOv2（ViT-B/14）对**完整 RGB** 提取 patch 特征，恢复 2D 排布后经 1×1 卷积投影；② 按有序二值 mask 的位置注入**槽位专属的可学习 prompt embedding**（如 object/target 两个槽，槽序固定、各学各的语义；不喂类别文本）；③ 轻量 transformer 对所有 token 联合上下文化；④ 聚合为紧凑场景表示（如 256 维）供下游策略。
- **关键性质：任何阶段都不删任何图像区域或 token**——mask 只提供空间引导。
- **mask 来源**：训练用仿真器 GT 分割；推理用外部 Grounding DINO → SAM 管线（文本查询→框→最高置信 mask），文本只进外部管线，不进编码器/策略。
- **MCR 增强**：训练时把 mask 并集区域随机着色，得 MCR 变体（推理开销不变）。
- **结果**（7 个仿真操纵环境）：空间偏移 60.7%、场景杂乱 59.7%（对照 DINOv2-DP 50.7% / 41.0%）；MCR 在未见颜色上 72.5%（对照最强 35.1%）。

**与本项目对照**：哲学同源（I0 追加 token / I1 残差注入 = "注入而非过滤"）。差异：它的底座是 DINOv2 + Diffusion Policy、mask 来自预训练 SAM、验证在仿真扰动；本项目底座 ACT + 自训 FCOS、透明杯完整分割不可靠故转向水面关键点、验证在真机闭环 + 洒水指标。**必引文献**；叙事上强调"透明杯上检测本身难"与"真机载水鲁棒性"两点差异化。

## 轴 4：底座 SOTA 全景（2025–2026，决定要不要换底座）

| 底座 | 出处 | 小数据（本项目 ~50 集）下的证据 |
|---|---|---|
| ACT | RSS 2023 | ≤50 demo 单任务桌面操作的**推荐默认**；弱点被坐实：**OOD 鲁棒性差**（插值型） |
| Diffusion Policy | IJRR 2025 | ICLR 2026 系统分析：小数据下 ≈ 动作查找表记忆，反而 **OOD 出奇地稳**；多模态演示时明显优于 ACT |
| π0 / π0.5 | arXiv:2410.24164 / 2504.16054 | 预训练带来插值 + 鲁棒兼得；但 100–500 demo 微调、A100 级训练，5090 不适配 |
| GR00T | 预训练 VLA | 同上；分析显示插值与 OOD 均佳 |
| ALT（Action Lookup Table） | ICLR 2026 | DP 小数据表现的显式化：查表即可匹配 DP，附 OOD 检测 |

实用指南（2026 共识）：≤50 demo、单策略任务 → ACT；多模态演示 → DP；需要语言条件/大泛化 → VLA。**数据质量 > 数量**（50 条干净演示胜过 500 条噪声）。

## 决策与建议

1. **不换底座**：本项目 50 集数据恰在 ACT 最优区间；离线阶段 E 已收敛、真机 A/B 是唯一待决证据，换底座会作废已验证的评估口径，且回答不了"检测注入有没有用"的研究问题。
2. **DP 同数据对照已被 P4 `DIFFUSION_NM` 覆盖**（2026-09-21 启动）——与本次检索建议一致，无需另起。ICLR 2026 结论提示：若真机 A/B 中 ACT 系对杯位偏移失败，DP 对照可能是最高杠杆解释。
3. **写论文必须引 RoboMP-DINOv2**，并说明本项目差异（自训 FCOS 在透明杯上、水面关键点、真机洒水指标）。预印本待核对。
4. **防洒杠杆**：若真机洒水严重，借鉴"流体仿真过滤抖动演示"或平滑正则（轴 1 文献一致指向），成本远低于换模型。
5. **注入源升级选项**：SAM2/GroundingDINO 预训练 mask 替换自训 FCOS 做一版对比（注入结构不变），对齐 RoboMP-DINOv2 以便横向比较；保留水面关键点（本项目独有信号）。
