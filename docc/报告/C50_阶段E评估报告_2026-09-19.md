## 1. 口径

- 四组各 100,000 步，同一数据集 `数据集/formal1_C50_nomaster`（train40，40 集 28,720 帧，8 维无主臂）；公共起点：seed=1000、batch=8、chunk_size=100、gripper_loss_weight=3.0、det_weight=1.0、主 lr 1e-5、backbone lr 1e-4、AMP 关闭。
- 组间唯一差别是检测注入方式：**ACT**＝无检测对照；**DET**＝FCOS 检测基线；**I0**＝token 注入（检测特征作为额外 encoder token，300→600）；**I1**＝残差注入（`cam + α·inject`，α 初值 0.05、可学习、clamp[0,1]，α=0 精确回退 DET）。**ACT 组首次加入**（阶段 C 只有 DET/I0/I1 三组短训），它是回答"检测到底带来什么"的必需对照。
- 评估集 = 固定 val10 `[7,11,13,14,16,27,35,38,40,43]`（10 集 7,180 帧，训练集之外；与阶段 C 的 dev8 不相交）。
- 工具 `src/lerobot/scripts/offline_eval_act_sequence.py`：逐帧时间序 teacher-forced 捕获完整 100 步动作块，batch=1；8 维无主臂、无需置零。启动脚本 `scripts/run_phaseE_val10_screening.sh`，汇总 `scripts/summarize_phaseE_val10.py`（复用阶段 C 指标定义）。
- 产物：服务器 `outputs/act_sequence_phaseE_2026-09-19/`（每 run 的 npz + results.json + evaluation.done，共 120M）；本地存 4×results.json、4×run 日志、`screen_summary.json`（gitignore）。
- 注意：ACT 的加权总损失与三组检测组不可直接比较（少一个检测项，约 0.55），损失轨迹仅作训练健康证据。

**结论要点：**

1. **相对 DET 基线：I1 与 I0 都通过筛选线**（阶段 C 10k 时只有 I1 通过；I0/DET 的 h0 由 1.128 转为 0.894 —— 短预算筛选低估了 I0，见 §6）。
2. **相对无检测的 ACT：没有任何检测组通过**。ACT 在 h0 精度（arm 2.6008 / grip 1.6170）与释放后阶段（post 1.9394）上四组最好；I1 最好分支（stage_grasp −6.9%）也没到 10% 线，且 h0_arm +5.6% 刚好越线。
3. 检测组里 **I1 综合最好**：三次对比中 h0 最优（2.7461/1.6874）、grasp 阶段与事件时序最优（|延迟| 1.5 帧）、queue_1 Δ² 与冲突 grip 优于 ACT；其短板是释放后阶段（post 比 ACT 差 32%，见 §5）。

排除项（§9 要求检查"少动所以平滑"）：

- 100k 时四组幅度比 1.35–1.78，**全部大于 1**（模型每步位移仍大于演示），不存在整体"少动"。
- 但相对参照的幅度差与平滑收益同量级：I1/DET 幅度比 0.871（−13%）≈ 冲突比 0.858（−14%）；I1/ACT 幅度比 0.942（−5.8%）≈ 冲突比 0.960（−4.0%）。因此 **I1 相对 DET 的平滑改善不能与"动得小"完全解耦**，但它的 h0 与 grasp 阶段同时改善 11.5%/14%，说明主要来自更准，不只是更安静；**I1 相对 ACT 的这点冲突优势（−4%）则无法排除幅度因素**，不作为证据。
- 事件时序正常：四组 |延迟| ≤ 2.4 帧（≤0.08 s），检出 10/10，无系统性丢失。

### 6.1 检查点趋势（20k/40k/60k/80k/100k，同口径）

四组 100k 训练同时保留了中间检查点，用完全相同的 val10 口径（同脚本、同 batch=1 逐帧捕获、同指标定义）对 20k/40k/60k/80k 重跑评估，与 100k 拼成轨迹（16 个中间 run 全部事件检出 10/10，`evaluation.done` 齐全）。全 12 列数据见附录 A。

h0_grip 比值（I1/ACT、I1/DET、I0/DET）：20k `0.803/0.823/1.049` → 40k `0.882/0.704/0.877` → 60k `1.061/0.838/0.928` → 80k `1.068/0.747/0.832` → 100k `1.044/0.801/0.847`；组间幅度比/冲突比等其余列随步数平缓，趋势与 h0 一致，未出现反转。

**1. 20k 的排序与终点排序几乎无关。** 20k 时 h0_arm 排序为 I1 < DET < ACT < I0，100k 为 ACT < I1 < I0 < DET —— 四个模型三个位置变了。两个关键配对的胜负**都发生在 20k–40k 窗口内**：I0/DET 从 1.082 越过 1.0 到 0.976（gripper 同上，1.049→0.877）；I1/ACT 从 0.932（I1 领先）升到 1.000（40k 恰好持平），此后稳定在 1.02–1.07。这正是阶段 C 用 10k 短训筛选得出"I0 不通过、I1 通过"却在 100k 翻转的直接解释：**反转点不在 10k，而在 20k–40k 之间**。

**2. 唯一早期即稳定、到 100k 不反转的关系是 I1 > DET**：该比值从 20k 起就 <1（0.970），其后 0.871–0.905 全程保持，gripper 同理（0.70–0.84）。检测注入相对纯检测基线的收益在训练很早期就出现，且不是短预算假象。

**3. ACT 终点领先来自中后期更陡的下降，而非检测通道拖慢早期。** 20k→40k ACT h0_arm 下降 21%（3.8664→3.0393），I1 为 16%、DET 仅 8%；60k 后差距进入平台。四组 h0_arm 全程单调下降，80k→100k 变化 ≤0.11（≤4%），gripper 在 60k 后有小幅波动（≤5%）——可判定 100k 已接近收敛，§4 的终点排序不是"还没训完"的假象。单 seed 观察，不作因果结论。

**4. 一处数据瑕疵（已定位，不影响结论）**：趋势表中 I1 s060000 的 `delay_grasp_frames = −10.1` / `delay_release_frames = −32.8` 是**单集伪影** —— ep16 在该检查点上事件检测器提前误触发（−118 / −340 帧），同集合在 20k/40k/80k/100k 均为正常值（如 100k 为 −4/+2）。剔除 ep16 后该 run 的延迟为 +1.9 / +1.3 帧，与相邻检查点一致；其余列不受影响。

## 7. 结论与下一步

- **部署候选仍是 I1**（检测组内综合最好、时序与平滑最优），但必须带上限定语：**它相对无检测 ACT 未过筛选线**（h0_arm +5.6%）。ACT-NM 在离线 teacher-forced 精度上四组第一。
- 现有离线口径测的是"对演示的复现精度"，回答不了检测组的预期收益（对杯位移/扰动的鲁棒性）——那正是 **真机验证**要回答的。下一步：真机 A/B，主对比 **ACT-NM vs I1-NM**（I0/DET 补全检测侧三接法，四臂都跑），固定杯位集、配对试验、记录成功率与失败类型；执行协议见 `docc/指南/C50_真机测试指南_round2_2026-09-19.md`（四臂 × 10 段 pilot，论文主表按每模型 ≥20–30 次扩试次）；temporal ensemble 系数（现部署 +0.03）的 A/B 同场进行。
- 部署接口检查项：-NM 模型 state 为 **8 维**（5 关节 + gripper.pos + load + curr，无 master_gripper.pos）、action 6 维；真机脚本的 state 组装需按 checkpoint 的 config.json 核对（旧真机指南针对 9 维含 master 模型）。
- 趋势捕获（20k/40k/60k/80k 同口径）已完成，结果见 §6.1 与附录 A；它同时给出一个方法论结论：**短预算（≤20k）的排序对终点排序没有预测力**（两个关键反转都在 20k–40k 之间），论文"短预算筛选"一节据此措辞。
