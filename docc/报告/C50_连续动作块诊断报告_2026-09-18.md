# C50 连续动作块诊断报告（2026-09-18）

## 0. 目的

回答真机"抽搐 / 卡顿"里模型侧占多大比重：把三个 C50 100k 模型在验证集上的**逐帧动作块**完整捕获下来，离线量化

1. 相邻帧动作块的时间一致性（同一未来时刻、不同起点的预测分歧）；
2. 各类执行 / 平滑策略回放后的跟踪误差与抖动；
3. 单帧推理时延分位。

本报告是 teacher-forced 离线诊断，**不是闭环成功率评估**，也不能单独判定启动抖动根因（那需要真机 A/B）。

## 1. 方法

- 工具：`src/lerobot/scripts/offline_eval_act_sequence.py`（随本报告同批入库；此前只做过旧 DET 的冒烟）。按 episode 时间序逐帧 `policy.predict_action_chunk`，落盘完整 100 步动作块（归一化 / 反归一化、真值、`action_is_pad` 有效性、state）为 npz，并写 `results.json`。
- 口径：teacher-forced、batch=1、`--raw-master-zero`（原始 `master_gripper.pos` 置零，模拟真机无主臂信号；图像与其余状态不变），固定 val10 = episodes 7,11,13,14,16,27,35,38,40,43，每模型 7180 帧。RTX 5090。
- 指标：
  - 块一致性 `C(t,h) = |pred[t,h] − pred[t+1,h−1]|`（第 t 帧预测未来第 t+h 帧 vs 第 t+1 帧预测同一绝对时刻），分档 h∈{1–5, 6–10, 11–30, 31–99}；
  - 执行回放：queue_k（每 k 步重规划）与 ensemble_c（**LeRobot 语义**：`wᵢ = exp(−c·i)`，`w₀` 是最旧预测），对比真值求 MAE、一阶差分 |Δ|、二阶差分 |Δ²|；
  - 时延：data_wait / preprocessor / network / postprocessor 的 p50/p95/p99（batch=1，预热剔除）。
- 运行：服务器 screen `seq_eval`，15:37:28 启动 DET→ACT→INJECT，16:10:04 `ALL_DONE`，三模型 rc=0。产物在服务器 `outputs/act_sequence_2026-09-18/<C50_x_zeromaster>/`（`results.json`、`episode_*_chunks.npz`、`ensemble_scan.json`）；本地有 results.json 与扫描 JSON 副本，npz 仅在服务器。
- 复现：`scripts/run_act_sequence_eval.sh`（评估）+ `scripts/scan_c50_sequence_ensemble.py`（系数扫描，含负系数）。

## 3. 结论

1. **模型侧抖动份额成立且可量化**：严格回放模型自产动作块（queue_1）时，二阶差分是演示自身的 **5.6×（DET）/ 7.0×（ACT）/ 8.2×（INJECT）**；一阶增量是演示步长的 1.5–1.8 倍。真机"抽搐"确有模型侧成分，不是纯控制集成问题。
2. **模型排序**：时间一致性（C(t,h) 全档）与平滑度（Δ²）均为 **DET < ACT < INJECT**，DET 最好；h0 精度 DET≈ACT>INJECT。真机定位排序（DET>INJECT>ACT）里 DET 第一在两处互证；ACT/INJECT 次序不同——teacher-forced 回放无闭环误差累积，次序以真机为准。
3. **夹爪反差**：主臂置零下 INJECT 夹爪 MAE 0.18，显著低于 DET 0.62 / ACT 0.58。INJECT 的夹爪对"无主臂信号"更鲁棒，是去主臂重训线（阶段 C/E）里值得重点看的部署候选。
4. **块保持越久边界跳变越大**（queue_10 的 Δ² ≥ queue_1 且 MAE 更差），继续印证 `n_action_steps=1` 是正确闭环形态。
5. **当前 temporal ensemble 配置（+0.03，偏旧）是"两头不讨好"**：MAE 0.217–0.241，为 queue_1 的 2.2–2.8 倍；且 Δ² 高于负系数。**负系数（偏新）在 MAE 与 Δ² 上同时占优**：−0.03 时三模型 MAE 0.140–0.155、Δ² 0.0005–0.0006（比 +0.03 平滑约 2 倍），且是 LeRobot 源码显式支持的合法配置（docstring：负系数给新动作更高权重）。INJECT 夹爪还随偏新单调改善（0.42→0.19）。
6. **时延充裕**：网络 p50 9–12 ms、p95 ≤17 ms，30Hz（33 ms）预算内，模型推理不是卡顿来源。
