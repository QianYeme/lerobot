# 三模型视觉敏感性评估报告（2026-09-16）

## 1. 结论摘要

在固定验证集上，三个模型都明确使用了 `observation.images.top`：错配或置空 top 图像后，预测动作发生明显变化，动作误差也一致升高。

- **C50_DET_s1000 综合表现最好**：干净图像下的抽样动作 L1 最低（`0.090072 ± 0.003275`），图像受扰后的误差增量也最小。它不是“忽略图像”，因为 swap action delta 仍达到 `0.215294 ± 0.000221`；更合理的解释是，它使用视觉但相对稳健。
- **C50_ACT_s1000 居中**：干净图像 L1 为 `0.098982 ± 0.000846`，swap 后误差增加 `0.247797 ± 0.005221`，显示出稳定的视觉依赖。
- **C50_INJECT_s1000 最敏感但不等于最好**：干净图像 L1 最高（`0.120329 ± 0.004724`），swap 和 blank 后的误差增量分别达到 `0.461596 ± 0.014348`、`0.403951 ± 0.002501`。这说明视觉注入形成了很强但较脆弱的耦合；当前证据不支持“注入提高动作准确率”，反而提示需要检查过度依赖或融合方式。

因此，现阶段优先候选是 **DET**，但最终模型选择仍应由真实机器人成功率决定，不能只依据离线敏感性。

## 2. 评估协议

| 项目 | 设置 |
|---|---|
| checkpoint | 三个模型的 `100000/pretrained_model` |
| 数据集 | `QYyyyyyyy/formal1_C` |
| 固定验证 episodes | `7,11,13,14,16,27,35,38,40,43` |
| 受扰相机 | `observation.images.top` |
| 随机种子 | `1000, 1001, 1002` |
| 每 seed 样本 | 100 batches × 8 = 800 frames |
| 每模型总样本 | 2400 frame samples |
| 动作范围 | 每帧预测块的前 10 个动作步 |
| 数值空间 | 与训练 loss 一致的归一化动作空间 |

每个 batch 比较三种输入：

1. `original`：原始状态与原始 top 图像；
2. `swapped`：状态不变，top 图像在 batch 内循环错配；
3. `blank`：状态不变，预处理后的 top 图像张量置零。

随机种子同时改变抽样帧顺序和 batch 内错配配对。以下标准差为 3 个 seeds 的总体标准差。

代表性运行命令如下：

```bash
/root/miniconda3/bin/python -m lerobot.scripts.eval_visual_sensitivity \
  --checkpoint outputs/train/C50_DET_s1000/checkpoints/100000/pretrained_model \
  --dataset.repo_id QYyyyyyyy/formal1_C \
  --dataset.root 数据集/formal1_C \
  --episodes 7,11,13,14,16,27,35,38,40,43 \
  --dataset.video_backend pyav \
  --camera-key observation.images.top \
  --batch-size 8 \
  --num-workers 0 \
  --max-batches 100 \
  --action-steps 10 \
  --seed 1000 \
  --output outputs/formal1_C50_phase1/visual_sensitivity_100k/C50_DET_s1000_seed1000.json
```

## 3. 汇总结果（mean ± std，n=3）

| Model | Original L1 | Swapped L1 | Blank L1 | Swap action delta | Blank action delta | Swap error increase | Blank error increase |
|---|---:|---:|---:|---:|---:|---:|---:|
| C50_ACT_s1000 | 0.098982 ± 0.000846 | 0.346779 ± 0.005108 | 0.204066 ± 0.004974 | 0.348809 ± 0.005369 | 0.212321 ± 0.003700 | 0.247797 ± 0.005221 | 0.105084 ± 0.004193 |
| C50_DET_s1000 | **0.090072 ± 0.003275** | **0.233468 ± 0.001033** | **0.174467 ± 0.005400** | 0.215294 ± 0.000221 | 0.155761 ± 0.004342 | **0.143396 ± 0.002909** | **0.084396 ± 0.003298** |
| C50_INJECT_s1000 | 0.120329 ± 0.004724 | 0.581925 ± 0.009835 | 0.524280 ± 0.005779 | 0.566687 ± 0.011531 | 0.511045 ± 0.003019 | 0.461596 ± 0.014348 | 0.403951 ± 0.002501 |

关键比较：

- DET 的 original L1 比 ACT 低约 **9.0%**；INJECT 比 ACT 高约 **21.6%**，比 DET 高约 **33.6%**。
- DET 的 swap error increase 比 ACT 低约 **42.1%**。
- INJECT 的 swap error increase 是 ACT 的 **1.86 倍**、DET 的 **3.22 倍**。
- INJECT 的 blank error increase 是 ACT 的 **3.84 倍**、DET 的 **4.79 倍**。

## 5. 与第一步完整离线评估的关系

固定 10 个验证 episodes、7180 frames 的完整 `offline_eval_act_det` 结果为：

| Model | Inference L1 | 相对 ACT |
|---|---:|---:|
| C50_ACT_s1000 | **0.328600** | 基准 |
| C50_DET_s1000 | 0.332163 | +1.08% |
| C50_INJECT_s1000 | 0.339984 | +3.46% |

完整离线评估中 ACT 略优，而视觉敏感性抽样的 original L1 中 DET 更优。这不构成矛盾：视觉评估只抽取每 seed 800 frames，并只比较动作块前 10 步；完整离线评估覆盖 7180 frames，统计口径不同。两个实验共同支持的稳健结论是：

- DET 没有显著牺牲动作精度，同时形成了明确且相对稳健的视觉响应；
- INJECT 没有带来动作精度收益，其更大的视觉响应主要表现为更大的扰动误差。

## 6. 限制

- 图像错配与置零属于干预测试，能证明策略输出依赖 top 图像，但不能单独证明策略关注了正确目标或学会了正确空间对应关系。
- blank 输入是训练分布外输入；它适合做相对诊断，不代表真实遮挡场景的绝对性能。
- 当前指标聚合了动作维度和 10 个时间步，可能掩盖机械臂位姿与夹爪通道的差异。
- 离线动作 L1 和视觉敏感性都不能替代真实机器人任务成功率。

## 7. 建议的下一步

1. **动作维度与时间步分解**：分别报告各动作维度、机械臂与夹爪通道，以及 10 个预测步随 horizon 的敏感性，定位 INJECT 的高增量来自哪里。
2. **检测质量验证**：在验证标注上计算定位 IoU、召回率/精度或 mAP，确认 DET 的检测头是否真的定位杯子，而不只看训练 loss。
3. **checkpoint 曲线**：对 20k/40k/60k/80k/100k 做相同的精度与敏感性评估，判断 100k 是否过拟合以及 INJECT 从何时开始变脆弱。
4. **受控真机 A/B 测试**：先人工确认 top/gripper 相机语义，在安全速度和空间限制下，固定起点与杯位序列比较三模型成功率；视觉遮挡或错位测试应单独、低速进行。
5. **模型选择**：若真机预算有限，先测 DET 与 ACT；INJECT 暂不作为首选，除非后续分维度结果和检测定位结果能解释其高敏感性。
