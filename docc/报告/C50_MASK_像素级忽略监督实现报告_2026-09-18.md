# MASK 像素级忽略监督：实现与验证

本次只修改 MASK 标签读取、辅助损失与测试。用户第0帧红/紫/蓝线作为大体结构参考保留，不填充为完整杯体标签，不继续全量 SAM 生成、不开始正式训练。

## 标签协议

每个 episode NPZ：

| 字段 | 形状 | 意义 |
| --- | --- | --- |
| `masks` | `(N,H,W)` | 前景目标，0–1；未知位置可填0，但不是背景标签 |
| `valid`（可选） | `(N,)` | 帧是否可用于分割监督；False 整帧忽略 |
| `valid_pixels`（可选） | `(N,H,W)` | True 为确定可监督像素；False 为未知，前景/背景都不判 |

有效前景=`masks=1, valid_pixels=True`；有效背景=`masks=0, valid_pixels=True`；未知=`valid_pixels=False`。最终有效性与帧有效性相交。数组必须对齐且有效性只允许0/1；仍要求 masks 有限且在0–1，不能把255或NaN作为忽略占位。

旧文件没有 `valid_pixels` 时默认整帧像素有效，保持原接口和旧训练行为；这只是兼容，不意味着此前 SAM 候选标签得到质量认可。`get_mask` 接口保留；模型使用新增 `get_mask_and_valid_pixels`。有效区域进入同一 LRU 缓存、同时淘汰；没有像素字段的旧文件不额外缓存整 episode 的全1像素数组。

## 损失及覆盖率

- BCE / L1 仅在有效像素求均值。
- Dice 的交集、预测面积和目标面积都屏蔽未知像素；各帧 Dice 损失按有效像素数量加权。空有效帧权重为0；整批为空时辅助损失为可反传的0，动作损失照常训练。
- 归一化及 Dice 累加转 FP32，避免半精度计数在480×640像素时溢出。没有新增模型参数或 checkpoint 键。
- `mask_valid_pixels` 改为真实有效像素数；`mask_coverage`=有效像素数/启用 mask 相机的所有可用像素数。现有离线评估已按该计数加权，无需改变动作评估。
- 未知像素的 decoder 输出梯度为0；不意味着共享骨干的相应空间特征完全无梯度，因为卷积感受野与动作损失仍可使用整个图像。真机动作推理仍不读取 mask。

## 实际验证

先写8项新测试：旧代码2项失败、6项报错，实际模型把应为4/0的有效像素数错误记为24,576/12,288。修改后8项通过。

补充480×640半精度测试发现 NaN，改 FP32 计数后9项全部通过。包括：有效像素公式、未知预测/目标不影响损失、未知梯度为0、全忽略、重复 batch、空帧、加载/旧格式/LRU、错误形状/有效性、真实模型前向与动作训练继续。

旧 MASK 11、INJECT 6、时序指标3项全部通过，共29项。本地 Python 无 torch，模型/梯度测试均在远程执行；不是本地 GPU 测试。

另使用 C50 真实图像、保存的八维处理器、随机初始化双相机640×480模型，batch2，人为构造257个有效像素与一帧全忽略：梯度有限且传到 mask decoder/FPN/backbone，未知输出梯度为0，移除 loader 后动作推理精确一致。覆盖率0.0004182943。这是接口/梯度 smoke，不是可用标签、分割准确率或训练成果。

## 下一步

1. 在用户已认可的抓持姿态上建立少量局部监督样例：杯体确定内部为前景、确定夹爪/背景为背景；模糊边界与结构难区分区域全部忽略。第0帧不自动连接轮廓，水面/杯底不得自动升级为整杯真值。
2. 逐帧报告有效前景与背景数量、覆盖率；仅有背景监督或几乎全未知的帧不能拿来证明杯子分割成功。SAM 可提供候选区域，SAM 多种输出一致或形态学收缩也不自动等于语义正确。
3. 在少量真实部分标签上验证辅助损失与梯度平衡，再进入同预算短训。当前 `check_c50_mask_training.py` 是原密集标签拟合工具，会因 coverage 不等于1拒绝部分标签；不要将该脚本的全像素 IoU 当作部分监督指标，后续需要明确适配再使用。

仅完成像素级忽略机制，不宣布 MASK 优化已证明有效或训练准备全部完成。
