# 真机测试经验与代码指令参考

> 用途:真机测试的快速参考——遇到的问题与解决、直接运行命令、以及简化原则。
> 原则:**真机测试默认直接运行**,不要叠加指纹、shadow 沙箱、保存文件锁等阻塞机制。

## 1. 本次真机测试遇到的问题与解决

### 1.1 动作卡顿(逐帧抖动)

- 现象:M0/M1/M2/M3 真机动作卡顿、不流畅。
- 根因:`--policy.temporal_ensemble_coeff` 默认 `None`,ACT 退回 `n_action_steps=1` 的 action queue 分支,每步只取 chunk 第一个原始预测、无时序平滑 → 逐帧抖。
- 解决:`control_f3.py` 入口默认改为 `0.01`,并在 `None` 时告警。真机推理始终显式带 `--policy.temporal_ensemble_coeff=0.01`。

### 1.2 M3_STOP 锁反复阻塞重复测试

- 现象:每次 M3 regulated 用 Ctrl+C 结束,下一次运行即报 `M3 intervention stopped for this session`。
- 根因:代码在 M3+regulated 以 `SAFETY_ABORT`(Ctrl+C/Esc)结束时自动写 `M3_STOP.json`,而 `check_execution` 发现该文件就拒绝后续运行。真机模型需要反复多轮测试,这种"保存文件阻塞推理"的机制每次都会自锁。
- 解决:写锁触发条件收窄为真异常 `ERROR` 与清理失败 `CLEANUP_ERROR`;手动 Ctrl+C/Esc(`SAFETY_ABORT`)不再自动锁。中止证据仍记录在每次 `summary.json`。**(已改)**

### 1.3 指纹 / Stage0 / shadow 三重门(过度阻塞)

- 现象:M3 regulated 运行前要求部署指纹(9 个源码文件的 code_sha256)与冻结配置一致、人工 Stage0 review、再跑 3 次 shadow 且 review 通过才放行。
- 结论:对反复试错的真机测试是浪费时间——shadow 只算残差不执行,对真机没有影响;指纹改一行代码就变,整个 review 链要重做。
- 决策:**以后不再设指纹、Stage0、shadow 三重门**。**(待从 control_f3.py 移除)**

## 2. 真机测试简化原则(以后默认)

1. 不要设置太多安全约束阻塞测试执行;真机模型需要反复多次测试,被锁/被门卡住只会拖慢迭代。
2. 不要设置"保存文件阻塞真机推理"的机制(如 M3_STOP.json 写完就挡下一次运行的锁),也不要让"同名试次目录已存在"挡住重测。重跑时应把上一次目录改名为 `<TRIAL_ID>_prev_<时间戳>` 保留证据,新一次照常写入,不需要手动删文件。
3. 不要像 M3 一样,运行前还要先跑 3 次对真机测试没有影响的 shadow/沙箱。
4. 真机场景没有那么脆弱,完全可以进行一定程度的试错;出现问题时人工停止即可。
5. 直接运行即可,参考 G1 指南(`experiments/position/g1_real_robot_generalization/index1/result/REAL_ROBOT_TEST_GUIDE.md`)——不设指纹、不设安全约束,浪费时间。

## 3. 标准直接运行命令(目标形态)

真机推理按 G1 风格直接运行,不带 `--prepare-only` / `--stage0-report` / `--shadow-review`:

```bash
python src/lerobot/scripts/control_f3.py \
  --bundle="$PWD/outputs/deploy/F3_R1" \
  --session-dir="$PWD/outputs/f3_r1/session_01" \
  --execute --model M3 --mode regulated --trial-id R02_M3 \
  --policy.device=cuda --policy.n_action_steps=1 \
  --policy.temporal_ensemble_coeff=0.01 \
  --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=nn \
  --robot.max_relative_target=5 \
  --robot.cameras="{top: {type: opencv, index_or_path: 4, width: 640, height: 480, fps: 30}, gripper: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --dataset.single_task="Cup pick and place" --dataset.num_episodes=1 \
  --dataset.episode_time_s=60 --dataset.reset_time_s=30 --dataset.fps=30 \
  2>&1 | tee "$PWD/outputs/f3_r1/session_01/$(date +%Y%m%d_%H%M%S).log"
```

> 注意:上为目标形态。当前 `control_f3.py` 仍要求 `--stage0-report`、M3 仍要求 `--shadow-review` + 3 次 shadow(指纹/Stage0/shadow 三重门未移除),`直接运行`要等这三重门从代码里去掉后才成立;M3_STOP 手动中止锁已移除。

结束一次 trial 用 Ctrl+C;要提前正常结束用右方向键 →(记 `OPERATOR_END`),两者都不会再锁。

## 4. 仍然保留的物理安全(不设流程门,物理安全照旧)

不设指纹/shadow/锁等流程门,但以下物理安全照旧:急停/断电方式随手可及;出现碰撞、夹爪挤压杯子、杯子倾倒、水洒、通信异常时立即人工停止;`max_relative_target` 保持安全值;半杯水、Home+Open 起始、工作区内无人员/线缆/易损物。
