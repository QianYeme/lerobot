# P03 研究背景
透明杯力控抓取面临三个核心挑战。第一，视觉感知困难——透明杯在RGB图像中几乎不可见。第二，力控接触判断——视觉无法判断夹爪是否接触杯壁。第三，泛化能力——训练集位置固定导致测试时过拟合。这三重挑战驱动了我们的方法设计。

# P04 实验平台
我们搭建了完整的物理实验平台。使用LeRobot SO-ARM101机械臂，配备两个RGB摄像头——上方全局视角和腕部近景视角。完成了两大类数据集共180个episode的远程操作采集，存储在LeRobot标准格式中。

# P05 数据集标注
采用双轨标注策略：检测标注用CVAT 1.1半自动标注，导出为XML格式。分割标注用SAM 2离线生成——从XML提取首帧bbox作为prompt，逐帧传播后高斯模糊，保存为NPZ文件。

# P06 模型架构总览
这是我们提出的M-VF-ACT模型架构。在原始ACT基础上新增了三个训练辅助分支——数据增强、FCOS检测头和Mask Decoder。关键设计是：三个辅助分支只在训练时存在，推理时丢弃，但它们的梯度已经塑造了共享的Backbone。

# P07 创新1: Mask-Guided Perception
这一页重点展开我们的核心创新。透明杯在RGB中几乎看不见——FCOS的稀疏bbox监督只能定位，无法刻画边缘。Mask Decoder用SAM2生成的逐像素mask作为训练标签，通过密集的L1 loss让Backbone学会区分透明杯和背景。这是FCOS和Mask Decoder的互补关系。

# P08 检测+Mask分支详解
这一页解释一个技术细节——为什么FCOS是三路并行而Mask Decoder是串行融合？根本原因是输出性质不同：FCOS输出稀疏的4个坐标，三层可以独立预测；Mask Decoder必须输出一张密集的480x640图，三层必须商量出一个统一结果。P2提供边缘细节，P4提供语义锚点。

# P09 实验计划
我们设计了6组核心实验，覆盖2个数据集乘以3个模型版本。所有实验使用统一的训练参数——120,000步、batch=8、chunk=100。评价指标仿照论文设计，分为四阶段成功率。预了6组对比维度来验证每个模块的独立贡献。

# P10 决策门
实验数据决定下一步方向，不靠直觉。如果E3/E6已经达到满意成功率，创新2/3/4留作未来工作。如果主要失败是接触延迟，立刻启动创新2的Visual-Force Fusion。如果是抓取力度不定，启动创新3的Hybrid Action Head。这是数据驱动的优先级决策框架。
