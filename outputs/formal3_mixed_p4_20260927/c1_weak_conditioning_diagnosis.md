# C1显式坐标弱使用诊断

状态：`CONFIRMED_BLOCKER`（2026-09-28快速反事实测试）。

## 现象

C1-100k的FCOS检测准确，但动作策略对显式框条件的因果响应太弱：左/中/右首帧框全部可见且`cx`顺序正确，坐标单独给出的pan方向也与GT一致；然而坐标条件产生的pan跨度仅`0.00561`（Gate要求`>=0.05`），置零框最大影响`0.00973`、左右反转框最大影响`0.00342`，均未通过box-effect Gate。该结果可解释“先向工作区中间伸出，随后才逐渐视觉追踪”的真机观察。

## 冻结判断

- 检测定位不是当前主要瓶颈；400帧抽样中C1平均IoU=`0.9117`、归一化中心误差=`0.00310`、漏检0。
- 继续延长相同C1训练或只提高检测损失，不能直接解决策略忽略坐标的问题。
- 不直接恢复已失败的C2 action residual，也不无门控地放大坐标分支，以免造成大幅抽搐。

## 下一轮候选方案

1. 在C1 state-box基础上增加反事实敏感性损失：同一非框视觉/状态下，normal、zero、左右交换框必须让第0步pan产生有方向的最小间隔，同时保留原动作回归损失。
2. 记录并约束`box_projection_norm / state_token_norm`，防止坐标投影在相加前后被尺度淹没；先做LayerNorm与有界可学习scale的短训消融。
3. 只做5k–10k短训筛选，并要求normal/zero/reverse、coordinate-only span、真实dev动作误差同时过Gate；未通过不得再次升到100k。
4. 备选为多层FiLM/交叉注意力条件化，但必须作为独立架构变量，不能和阶段辅助监督同时加入首轮消融。

## 预注册Gate建议

- `coordinate_only_span >= 0.05`；
- `max(zero_effect, reverse_effect) >= 0.01`，并提高目标到`0.02`作为优选线；
- 左/中/右第0步pan方向与GT一致；
- DET定位不得明显退化；
- dev12第0步及全轨迹误差不劣于DET基线；
- 不以teacher-forced Gate代替真机闭环证据。
