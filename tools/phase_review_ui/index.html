动作边界确认

三个审核项与四个训练阶段
  1. 闭爪区间：从夹爪开始持续向内运动，到闭合动作基本稳定。审核整个范围，不必争论唯一一帧。
  2. 抬升开始：机械臂真正开始向上或搬运杯子的边界，可晚于闭爪稳定。
  3. 释放区间：从放置后夹爪开始张开，到张开动作基本稳定。
  4. 训练映射：闭爪前是 approach，闭爪开始至抬升是 grasp，抬升至释放是 lift_place，释放以后是 release。
