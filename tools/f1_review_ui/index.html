标注说明：接触 ≠ 闭爪 ≠ 离桌
PRECONTACT · 尚未接触
看得见夹爪与杯子之间仍有间隙；接触前的闭爪也可以属于此类。
CONTACT_SUPPORTED · 接触有支持
可见接触，或随后杯子随夹爪共同运动支持接触。不要求证明离桌；不能仅凭夹爪闭合判断。
CLOSING / POST_CLOSE / RELEASE
分别是闭爪过程、闭爪结束到释放前、张爪释放过程。它们是动作阶段，不是抓稳或落桌真值。
UNKNOWN / OCCLUDED
已看过但不能判定 / 被遮挡。填写不确定起止帧和原因，可靠帧留空。

接触标签与阶段标签是两条轴，可以重叠；同轴不同可靠类别不能重叠。不确定边界不得放进可靠区间。可为同一标签添加多段。

可靠区间标注

先连续播放，再逐帧核对。每段选择标签、填写帧号与可见证据；不确定的边界可另加一段 UNKNOWN。
