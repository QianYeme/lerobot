# Minimal compatibility proposal — NOT APPROVED / NOT EXECUTED

## 所需决定

r2 要求保留原 P1 来源规则，同时禁止新增人工目标输入；实际原规则需要人工目标中心。该矛盾不能通过工程修补消除。建议下一轮只改变**原型来源授权**，保持 ACT/P1 架构和 Legacy/Fixed 唯一在线预处理变量。

推荐供审批的最小方案：允许对四张预先确定的 **Train35** 图像各提供一个目标中心和固定采样范围，以原有均值+L2规则构造同一份4原型 bank，Legacy/Fixed共享文件哈希。帧选择在查看模型结果前冻结，不能从 Dev 或 simulator GT 获得坐标。明确称为“少量人工目标先验”，不得称为无标注/无监督。新物体分辨率、遮挡及采样范围需要预先定义，不能擅自照搬杯子35px作为等价尺度。

公平性：P1相比ACT获得额外目标先验，必须披露标注量/选择和DINO原型构建成本；ACT vs P1只能作方法级比较，Legacy vs Fixed 才是在线归一化受控比较。即使获批也须先做 train-only 原型目标/机械臂/背景响应检查、真实batch/恢复smoke，再测1/2/3并行有效吞吐；本轮没有这些结果。

如必须坚持不新增任何人工输入，则保持本轮阻断，另行批准一个自动原型发现研究任务；任何KMeans/交互分割/随机patch方案均是新科研变量，不是原P1的无损迁移。本提案未实现这些算法。

时基仍需在下一决策写清：沿用原生20Hz控制、不插帧不重复动作时，训练10FPS索引如何解释；冻结同一闭环初始化/最大步数后再运行三组10k。不能以本轮元数据核验代替闭环验证。
