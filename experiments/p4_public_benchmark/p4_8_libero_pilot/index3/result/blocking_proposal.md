# Blocking proposal — not approved / not implemented

本轮G2实现按原样冻结后完成。发现池只有12个patch/7集，低于实现前预注册的16个候选门槛；12集Train-only保留审计中仅7个proxy正例。16是执行者在实现前选择的保守覆盖启发式，**不是decision指定的数字，也不是统计显著性界限**。没有根据结果改成12。

更关键的是，事后时序可视化提示桌面/机械臂污染。减少候选数门槛不会解决遮挡后光流跟错对象的问题。暂不建议把这份bank用于三模型10k训练，不能将它包装为已经证实的自动目标库。

最小后续方案供用户与规划助手选择：

1. 若优先完成与历史P1最接近的LIBERO迁移：明确批准由Codex查看预先固定的4张Train图像，指定目标内部采样中心；完全披露为少量执行者目标先验，不能称无标注。可复用历史均值+L2原型机制，保持两P1同一bank、只变在线标准化；需要新decision覆盖r3的禁止条款，本轮未这样做。
2. 若必须全自动：另立一轮自动目标发现改进合同，加入遮挡/新显露检测以及更完整的机器人外观负例，或另行授权公开预训练语义定位器。两者都是新增算法变量，不能偷偷添加到当前V1。当前冻结V1保留为失败证据；新方法需重新预注册，在Train-only资料上验证，不能用Dev/rollout调bank。

时基还需明确：原生20Hz单动作step已实测，但10FPS转换物理来源不完整。可以明确批准官方原生按索引执行协议并披露非物理时间等价，或补转换来源证据；不擅改频率/重复/插值动作。

G2通过后才补两P1实际网络smoke、共享初始化/主干输入不变核验、单/双/三路吞吐探针，再启动原三组10k与10次配对闭环。当前没有后台正式训练等待执行，也没有自动越过gate的定时器。
