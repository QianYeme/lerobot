# 只需新增六集接触区间

页面：http://127.0.0.1:8767 。顺序：Train10 → 19 → 29 → 38 → 49 → 57。它们仍是原Train的一部分，只在本pilot作独立验证，不是正式Dev/Test。

1. 填审核者，先连续播放双视角；左top、右腕部。
2. 添加PRECONTACT段，取确实尚未接触的可靠开始/结束；可包含接触前闭爪。
3. 添加CONTACT_SUPPORTED段，取RGB接触或后续杯子共同运动可支持的可靠帧；仅夹爪闭合不够。不要把未确认遮挡段整段外推。
4. 不清楚的边界留间隙，或添加UNKNOWN/OCCLUDED，填写不确定起止与原因，不填可靠帧。无需猜精确接触瞬间，无需覆盖整集。
5. 填证据说明，完整条目停输1秒后自动写CSV；等待绿色“已写入并回读确认”。若仍有未完成段先完成或删掉，该段草稿只在浏览器保留。也可点“立即保存”。
6. 完成六集后告知执行端。无需重复旧六集，也无需新增动作阶段类。不要查看load/current、模型分数、原Dev/Final或自己换片段。

起止帧两端包含，视频从原episode第0帧起算；W15分析需目标帧≥16，但审核可从第0帧开始，程序会排除历史不足帧。需要至少4/6集两类各5个可靠目标帧；不为达标硬填。

重启：在项目根目录执行：

```powershell
python scripts/run_f1_review_ui.py --result experiments/force/f1p_contact_signal_pilot/index1/result --port 8767
```

新审核CSV就在本目录review_intervals.csv；同目录csv_backups保留每次写前备份。出错不要刷新，先下载草稿；若提示版本冲突，先保留草稿再重新载入。保存仅保存区间，不代表整集或F1P自动完成。
