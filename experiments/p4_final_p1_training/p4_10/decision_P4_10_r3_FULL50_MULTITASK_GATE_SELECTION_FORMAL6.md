# decision.md — P4.10-r3：LIBERO 每任务全50初态配对评估 + 多任务 Gate 选择 + formal6 最终候选筛选

日期：2026-10-31
状态：**冻结研发阶段执行授权**；最终 80k 训练与真机动作须另行 decision 授权。
替代：P4.10-r2 中对“同一个任务必须再找50个全新官方初态”的额外要求，以及与之冲突的独立起点硬性阻断。保留 P4.8、P4.9、P4.10-r0/r1/r2 的历史数据与版本，不覆盖。
目标：判断 Object Path 是否真正帮助完成闭环任务，筛选可学习 Gate alpha 的初始化策略，然后分别为 SO-101 真机 L1 Legacy Seed1、F3 Fixed Seed3 推荐可进入最终 80k 的配置。

## 0. 冻结语义：为什么现在这样改

1. LIBERO 包含多个套件；`libero_object` 包含10个任务。当前已有大量数据来自其中的 task0（罐头入篮）。每任务的标准评估由官方 init bank 提供，常见约50个固定起点；**以当前本机 `get_task_init_states(task_id)` 的真实长度为准，不凭空补凑**。
2. 每个候选模型允许在同一任务上**重复使用全部官方初始状态**进行配对评估。起点并未因一次 rollout 而“耗尽”，无需为开发筛选再造50个。跨模型保持相同 task_id、init_index、episode budget、成功判定与推理设置。
3. 但用于挑选 Gate 的起点属于**开发/模型选择评估**，不能之后又称为“完全独立、未参与模型选择的最终测试”。多训练seed可检查稳定性，不能让固定初态自动变成新的独立测试集。
4. 本轮重点是 LIBERO-Object 的多任务开发评估，不等于执行官方终身学习/多任务统一模型协议；当前各任务**独立训练单任务策略**，不同任务必须构建各自 Train-only 目标原型。不能把 task0 的原型、权重直接当作其他任务的合法训练结果。
5. Gate 指 **有符号、可学习标量 α 的初始化值**；固定 α 是独立实验。仅 Gate 不同的配对实验必须有相同的其他初始张量、样本顺序、原型、训练配方与步数。训练结束的 α 值不是预设固定值。

## 1. 总体实施：三层证据 + 分阶段成本门槛

- **阶段 A（当前任务，低成本）：** 完成 task0 语义审核、固定Gate机制对照；用全部可用约50官方起点对 Gate 候选进行配对开发评估、至少2训练seed；不存在“必须另有50个未用起点”的阻断。
- **阶段 B（跨任务，逐步扩展）：** 先固定两个补充的 LIBERO-Object 任务（与 task0 构成3任务最小集合，优先目标外观/位置/操作差异较大的任务）；每任务独立 Train-only 原型与模型训练；每任务评估全部官方起点。根据结果决定是否再扩展全部10任务；**不默认一次训练10任务×所有Gate×多seed**。
- **阶段 C（真机目标域）：** formal6 120 episodes 使用冻结 Train90/Dev15/Final15，在 Legacy Seed1 和 Fixed Seed3 上进行20k配对小预算筛选。只推荐候选，不自动训练80k或操作真机。
- **阶段 D（另批）：** 推荐方案及证据经用户批准后，分别训练最终 L1/F3 Gate-Selected Seed1/Seed3 80k；本地4060 Smoke、受监督真机配对测试，原版L1/F3保持为对照。

## 2. 先行 Gate 集合、预算、对照定义

A0. 启动前审计 P4.10-r0 的 checkpoint、数据/原型hash、训练初始权重和全部配置；历史5k结果若来源完整可复用；若配对条件不成立，涉及的组必须在相同配方下重新训练，不混用10k与5k。

A1. 首轮候选冻结 `alpha_init in {0, +0.01, +0.05, +0.1}`，均为可学习 α；`+0.001`与`-0.01`历史负结果仅作为旁证，不必须重训。对照为同预算**匹配 NOOBJ/ACT**（移除Object分支从头训练，保持匹配机器人状态/相机/训练配置），不是在P1推理时把Object关掉。

A2. 首轮统一训练预算 **5k**。若出现全部低成功率/明显欠拟合，先冻结**整个比较组**统一延长至10k，不只给获胜Gate加训。每个比较组至少2个训练seed（先复用已验证seed，第二seed统一从头配对）；多seed仅计算与资源允许下的初期稳定性，不声称完整统计显著。

A3. `alpha_init=+0.05`另有固定 α=0.05 的5k机制对照，用以区分“初始化给了早期梯度”与“训练后需要可学习门控”；固定Gate模型不混入单一可学习Gate排名。

A4. Legacy 与 Fixed 在线 DINO 的标准化差异、Proto bank均来自既有历史实现。此轮 LIBERO **首先用Fixed统一选候选**，避免额外维度爆炸；是否对Legacy在任务集上进行小规模验证由阶段B的门槛决定。**不能**仅凭 LIBERO Fixed 排名给真机 L1 指定最优Gate。

## 3. 阶段A：task0，全50状态与语义/因果诊断

A5. Codex查询 task0 官方init bank大小、合法索引、数据hash、成功判定和最长episode steps。对每个模型、每个seed遍历同一个完整 init index 列表（若确实50则`0..49`），保存逐起点成功、轨迹长度、失败阶段、异常、可复现来源；重跑必须写明用途与去重键。

A6. 复用先前 `+0.05` 与 NOOBJ 成功/失败配对样本的视频与哈希，重新抽取带时间对齐的 DINO 相似度热图：靠近、夹取、抬升、搬运、放置。目标语义审查分成 `TARGET / ARM / BACKGROUND / AMBIGUOUS / OCCLUDED`，附关键帧和执行者审阅记录，禁止用 rollout 的目标真值或仿真 segmentation 来倒推训练原型。

A7. 每模型评估：成功率（每训练seed分别报告，任务内配对差异）、Dev动作误差、Gate轨迹、Object残差L2/Query L2、Object ON/OFF 动作变化、梯度L2、原型目标响应；同时保存拒绝方案的理由。ON/OFF只是机制探针，不能替代NOOBJ训练消融。

A8. Gate筛选：成功率与跨seed方向为主要指标；Object Path有效响应和目标语义是准入门槛。预先定义非劣容忍范围与多指标排序规则，不能看到成绩后随意改评价指标。若2个候选差异处在少量rollout波动范围，保留并列候选，不强制选唯一赢家。

## 4. 阶段B：LIBERO-Object 跨任务验证

B0. 在访问新增任务成功率前，从10任务列表中**预先固定两个不同于task0的任务ID、指令、训练集可用性、官方init数量、目标性质与选择理由**；不得因为测试效果差而换任务。与task0组成3任务开发集；所有任务使用相同候选Gate策略和固定预算。

B1. 每新增任务按真机同源方法：冻结 Train episode 清单，按0/25/50/75%序位选四集，各取25%进度Top帧，Codex实际看图指定目标内部坐标，按相对尺度映射35px@640x480的局部椭圆采样，DINOv2-S/14单次标准化提取4×384 prototype；落盘帧hash、坐标、overlay、bank hash与来源。图像视角映射需核对，**禁止**复制罐头坐标/原型，不能使用Dev或评估初态生成prototype。

B2. 资源优先策略：每新增任务先训练 NOOBJ 与 Fixed `Gate=0`、`+0.05` 三组（seed配对、统一5k），同任务对全部官方init评估；如task0证据支持`+0.01`或`+0.1`更稳，可在新任务训练前由预先冻结的选择规则**替代+0.05**，而非看完新任务结果后追加获胜者。若阶段A保留两个近似并列Gate，允许两个Gate都测试，但必须同等成本同等准则。

B3. 至少两个任务上的结果记录**任务内差异**（Gate候选-匹配ACT、Gate候选-Gate0），再做任务等权汇总，绝不可把同一任务内50起点误当成50个独立任务。每个任务仍分别报告任务成功率与随机seed方差；不能因一个任务成功就认定通用最优。

B4. 扩展全部LIBERO-Object10任务属于**可选下一门槛**：仅当3任务已存在一致的行为收益、原型语义合理、训练预算和并行吞吐有记录时，Codex提交单独扩展Proposal和成本估算；本r3不授权自动开始剩余7任务训练。

## 5. 阶段C：formal6 20k 准入筛选（优先与B并行筹备，执行需满足门槛）

C0. 阶段A的训练来源合法、Gate候选冻结、目标原型审查不存在确定性重大错误后即可开始；不因跨任务评估的统计不显著无限期等待，但须标注证据级别。

C1. formal6冻结 `QYyyyyyyy/formal6_merged` 的120集，Train90/Dev15/Final15；只用Train90建模和历史同源4×384杯原型，Dev15做模型选择，Final15封存。确认相机Top/Wrist、原始模型P1_OCACT结构、8D状态和6D关节位置动作等全部沿用历史。L1是Legacy seed1，F3是Fixed seed3。

C2. 每条架构至少包含**Gate=0**与**候选非零Gate**的20k从头配对训练；若有第二个并列候选，可增加一个。`alpha_init`是唯一可改训练变量。除Gate外初始权重逐张量一致，数据顺序与batch样本hash一致；如果历史20k基线无法证明来源配对则重跑同预算基线。L1 与 F3 seed不同，严禁把它们当单一变量的Legacy/Fixed消融。

C3. 比较Dev15 chunk-valid Arm/Gripper MAE、按接近/抓取/抬升/运输/放置阶段误差（有可信标签才能统计，否则标不可用）、Gate和残差/Query尺度、ON/OFF、输出安全边界与故障率。因旧formal6 Gate+.001 80k出现离线退化，对新Gate不预设优越性，且20k离线不能代替受监督真机闭环成功率。

C4. 输出`L1_gate_candidate`、`F3_gate_candidate`（可不同、相同、或零），并写明是否值得最终80k。若没有真实收益或安全/稳定性不达标，明确`KEEP_ORIGINAL`或`INCONCLUSIVE`，不为了必须选新Gate而强行替换。

## 6. 排程与准停机制

- 唯一的本地Codex通过SSH连接RTX5090；先检查现有训练/显存/存储，绝不覆盖P4.7、P4.8、P4.9结果。优先重用已有5k模型和已导出视频，避免重复训练。
- 并发数量由实测有效aggregate steps/s、峰值显存、OOM风险决定（1/2/3/4进程压力测试），优先并行短训练与只读评估；不必为了GPU满载而强制4路。
- 每个任务持久会话、明确PID、日志、完整可恢复checkpoint、重启机制、hash。断线不终止，失败单任务隔离；不可因未达到理想成功率擅自延长训练或换数据。
- 若无法可靠查看目标图/制作热图，标`SEMANTIC_REVIEW_INCOMPLETE`，保留已完成合法训练结果但**暂停依赖该证据的跨任务建库**；提交Proposal，不编造目标位置。
- 本轮不执行无人监督真机运动、Final15评估、HF发布或最终80k训练。任何阶段出现来源不一致、数据泄漏、目标原型不合法等，停止相应分支并留阻断建议，不连坐独立合法分支。

## 8. 禁止误导性结论

- “全部50起点评估”≠“50个独立新测试样本”≠“模型训练里没有见过任何相似物体位置”；明确官方状态与训练演示的关系有待审计。
- 已用于调Gate的task0全部50是**开发评估**；同任务多次复用和多seed可比较鲁棒性，但不能标为未参与模型选择的最终hold-out。
- 3任务单任务策略比较≠完整LIBERO-Object10任务官方成绩；各任务的prototype含少量Codex目标位置弱先验，ACT没有相同先验，故P1 vs ACT是系统级比较；Gate0 vs Gate+（同架构同原型）才是单变量对比。
- 选出来的是**Gate初始化候选**，不是已证明最优，更不是已获批准的最终真机模型；最终需要单独80k与受监督闭环测试。
